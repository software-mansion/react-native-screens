# Deferred push

1. Tap **Hold fade**. The source stays visible while the status changes to
   **Destination laid out**. Tap **Release** to play the fade. The status changes
   to **Appeared** when the transition finishes.
2. Remove the destination and repeat with **Hold slide**. Wait without pressing
   **Release**. After one second the slide starts on its own.
3. Remove the destination during a hold. On Android, the source should stay
   visible through removal. Push again and release the new destination.
4. Start the system back gesture and cancel it. The destination stays open.
   Complete the gesture to return to the source.
