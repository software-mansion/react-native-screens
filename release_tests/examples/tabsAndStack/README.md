# tabsAndStack

Tabs + Stack v5 from the main `react-native-screens` export.

## Requirements

|         |                                                                                                         |
| ------- | ------------------------------------------------------------------------------------------------------- |
| **RNS** | 5.x                                                                                                     |
| **RN**  | Fabric required (RN ≥ 0.76). Match the RNS ↔ RN matrix from the library README for the release you use. |

## Imports

- `Stack`, `Tabs` from `react-native-screens`
- `SafeAreaView` from `react-native-screens/experimental`

## Setup

```bash
node create_playground.js -s current -e tabsAndStack
# or
node create_playground.js -s 5.0.0-alpha.1 -r 0.84.0 -e tabsAndStack
```
