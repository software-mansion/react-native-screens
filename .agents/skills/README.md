# Shared skills

Skills shared by everyone working on this repository live here, one directory
per skill with a `SKILL.md` inside. This is the cross-agent location; Claude
Code picks them up through links created by `yarn sync-agent-skills`.

Everything in this directory is gitignored unless explicitly opted in, so
skills you installed locally stay local. See "AI tooling" in
[`CONTRIBUTING.md`](../../guides/CONTRIBUTING.md) for how to add one.
